# JAGMUN II — Official Website

This is the official website for JAGMUN II, the second iteration of the Jaguar Model United Nations conference hosted at the University of Miami. The conference is scheduled for September 27-28, 2026.

## What this is

A single-page website built as the public face of the conference. It has a loading intro animation, a background video that plays on loop in a boomerang style, a navigation bar with dropdown menus, and buttons for registration and committees.

## How it's built

The site is a single HTML file with no build step or framework setup required. It runs entirely in the browser using React loaded from a CDN, Babel for JSX transpilation, Tailwind CSS for styling, and GSAP for animations. You just open the file and it works.

## File structure

```
index.html              the whole site lives here
assets/
  jagmun-logo.png       the JagMUN logo, used in the nav and as the browser tab icon
README.md               this file
```

## Running it locally

Just open `index.html` in a browser. No installs, no terminal commands needed.

## Hosting

The site is hosted on GitHub Pages directly from the root of this repository.
